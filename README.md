# Nevşehir Korsan Taksi

Nevşehir korsan taksi yolcusunun çoğu otel misafiridir. Kapadokya Havalimanı Gülşehir yönünde kalır; Nevşehir merkezden 31 kilometre, Avanos'tan 35, Ürgüp'ten 48 kilometredir. Kayseri'ye inen yolcu için de karşılama yapılır, uçuş hangi terminale ise araç oraya gider.

Çalışır. Balon firmasının servisine yetişemeyen ya da kalkışı yerden izlemek isteyenler gün doğmadan seyir tepesine götürülür. Gündüz Derinkuyu yeraltı şehri ve Hacıbektaş'taki dergâh için sefer yapılır; Derinkuyu havalimanına 59 kilometredir.
